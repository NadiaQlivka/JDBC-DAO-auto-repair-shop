# Auto Repair Shop Management System

Курсовой проект по разработке информационной системы управления автосервисом с использованием Java и PostgreSQL.

## Технологии

Java 21, PostgreSQL, SQL, PL/pgSQL, JDBC, Maven, Swing.

## Функциональность

- Проектирование реляционной базы данных с ограничениями целостности.
- Реализация CRUD-операций с использованием JDBC и паттерна DAO.
- Разработка хранимых процедур, функций, триггеров и курсоров на PL/pgSQL.
- Формирование аналитических отчётов:
  - расчёт стоимости обслуживания отечественных и иностранных автомобилей за выбранный период;
  - рейтинг пяти мастеров по количеству обслуженных автомобилей за месяц.
- Авторизация пользователей и разграничение прав доступа.
- Защита учётных данных с использованием Argon2id и HMAC-SHA256.
- Графический пользовательский интерфейс на Java Swing.

## Запуск

Для работы необходимы Java 21, Maven и PostgreSQL с предварительно созданной схемой базы данных, процедурами и пользователями.

1. Клонировать репозиторий.
2. Перейти в каталог `demo`.
3. Настроить переменные окружения:
   - `DB_URL` — JDBC URL базы данных PostgreSQL.
   - `LOGIN_HASH_KEY` — секретный ключ HMAC-SHA256 в формате Base64.
4. Запустить приложение:

```bash
mvn compile exec:java -Dexec.mainClass=autoservice.app.App
```

Для входа используются учётные данные пользователя PostgreSQL, настроенного для приложения.
